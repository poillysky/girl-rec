# GirlRec 前端视觉规范（Design Guide）

> 本文件是前端美化的唯一依据。任何页面改动前，先读本文件；改动后对照验收清单自检。
> 技术栈：Vue3 + Vite + Naive UI（darkTheme）+ lucide-vue-next 图标 + 手写 CSS 令牌层。

---

## 1. 设计语言

- 暗色监控后台。基调深蓝黑，信息密度中等偏紧凑，状态可视优先（直播/录制/异常用颜色+呼吸点表达）。
- 层级：侧边栏导航（分组）→ 页面标题 + 关键指标（顶栏/统计条）→ 内容区（卡片 → 表格/列表）。
- 交互反馈：所有可点击元素有 hover/focus 态；危险操作（删除/停用）二次确认；写操作成功 toast 提示。

## 2. 颜色令牌（CSS 变量，style.css）

| 变量 | 值 | 用途 |
|---|---|---|
| `--bg` | `#0b0d12` | 页面底色 |
| `--panel` | `#141722` | 卡片/侧栏 |
| `--panel-2` | `#1d2130` | 次级面板/表头 |
| `--border` | `rgba(255,255,255,.08)` | 分隔线 |
| `--text` | `#e6e9f0` | 主文字 |
| `--dim` | `#8b93a7` | 次要文字 |
| `--dim-2` | `#5a6172` | 弱文字/分组标题 |
| `--accent` | `#4f8cff` | 主色（选中/链接/激活） |
| `--green` | `#34d399` | 直播中/成功 |
| `--amber` | `#fbbf24` | 探测中/警告 |
| `--red` | `#f87171` | 失败/删除 |
| `--purple` | `#a78bfa` | 重要/其他 |
| `--cyan` | `#22d3ee` | 信息/图文 |

原则：主色只用于"当前激活"，状态色只用于状态表达，禁止无意义彩色。

## 3. 间距与尺寸

- 间距基元 `--sp-1..5`（4/8/12/16/24px）；卡片内边距 20px，卡片间距 16px。
- 圆角：卡片 12px、按钮/输入 8px、标签/徽标 99px。
- 表格行高 44px；按钮高度 sm 28px / 默认 34px / lg 40px。
- 侧边栏 224px（≤900px 折叠为 72px 图标栏）；顶栏 60px。

## 4. 组件选用（Naive UI）

| 场景 | 组件 | 说明 |
|---|---|---|
| 导航 | `n-menu`（type 分组） | 分组标题+菜单项，选中态由组件保证 |
| 表格 | `n-data-table` | 列对齐/排序/空态统一 |
| 弹窗 | `n-modal` + `n-card` | 内置遮罩/关闭/滚动 |
| 开关 | `n-switch` | 启用/重要 |
| 按钮 | `n-button`（secondary/error） | 危险操作 error 类型 |
| 输入 | `n-input` / `n-select` | 表单 |
| 消息 | `n-message` | 全局 toast，useMessage() |
| 确认 | `n-dialog`（useDialog().warning） | 删除确认 |
| 进度 | `n-progress`（line） | 录制进度 |
| 统计 | 手写 `stat-grid` | 卡片自家样式，组件太笨重 |

## 5. 图标（lucide-vue-next）

- 尺寸：菜单 18px、按钮内 16px、统计卡 22px；`stroke-width=1.8`。
- 状态语义：直播 `Radio`、监控 `Activity`、房间 `Video`、文件 `FolderOpen`、配置 `Settings`。

## 6. 页面结构约定

1. 页面容器：`<div class="page">`（padding 24px，flex column gap 16px）
2. 顶部：标题行（`h2` + 副标题 dim，右侧操作区）
3. 统计条（如适用）：stat-grid 一行 4-5 卡
4. 筛选条：搜索输入 + 下拉 + 右对齐按钮
5. 主体：卡片（card 头部标题+操作，body 内容）
6. 空态：`.empty`（图标 + dim 文案 + 可操作按钮）

## 7. 验收清单（每次改动后自检）

- [ ] 菜单选中态正确、分组标题可读（不堆叠）
- [ ] 表格列对齐：ID/操作用例居中，数字（大小/时长）右对齐等宽
- [ ] 弹窗不溢出视口，内容多时内部滚动，关闭/ESC 可用
- [ ] 危险操作有确认弹窗；写操作有 toast 反馈
- [ ] 状态色语义正确（绿=直播中、黄=探测、红=失败，不在别处滥用）
- [ ] 暗色对比达标：正文 `--text` 在 `--panel` 上对比度 > 7
- [ ] 900px 折叠：侧栏图标栏可用，无横向溢出
- [ ] `npm run build` 通过，无 console 报错
